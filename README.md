The Isle of Five More Minutes — a treasure map of a fictional island where nobody ever gets up. Ten labeled places (Mount Snooze, The Yawning Cliffs, Duvet Downs, The Land of Nod, The Long Lie-In, Port Doze, The Snooze Button, Pillow Bay, Alarm Rock, and the treasure itself, The Perfect Nap), a numbered route from Port Doze to a red X, the Whale That Overslept, a compass that says "N (ask again tomorrow)", and a scale a snail takes 2 hours to cross. Drawn as SVG and rendered to a single 1024×1024 PNG.

## Run it

python3 main.py
